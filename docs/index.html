About this demo
  • Model: MobileNetV2 fine-tuned on TrashNet (MIT), static int8 ONNX (2.6 MB), run with onnxruntime-web (WebAssembly).
  • On the 379 held-out TrashNet test images the int8 model scores 90.5% accuracy and 88.9% macro-F1 (fp32: 91.3% / 89.8%; single training seed). Source: reports/onnx_benchmark.json.
  • TrashNet photos have plain backgrounds and one item per photo. Expect weaker results on cluttered real-world photos; the model has no "unknown object" class.
  • Scores are softmax outputs, not calibrated probabilities. Below 0.40 top score the demo says "not sure", the same rule as the CLI and Streamlit app.
  • Sample images are from the project's test split, courtesy of Gary Thung and Mindy Yang.
